## 1. Introduction

The Notice Board CLI is a terminal-based application developed using Bash shell scripting. It allows users to manage college notices through a simple command-line interface.

The project demonstrates Linux commands, shell scripting, file handling, searching, sorting, backup operations and task automation.

## 2. Objectives

- To develop a notice management system using Bash.
- To add and display college notices.
- To search notices using keywords.
- To identify HIGH priority notices.
- To archive notices older than 30 days.
- To create backups of notice data.
- To automate archiving using cron.

## 3. Technologies Used

- Operating System: Ubuntu Linux
- Environment: Windows Subsystem for Linux (WSL)
- Language: Bash Shell Scripting
- Commands: grep, sort, head, tar, date, mkdir, chmod
- Scheduler: Cron
- Editor: Nano

## 4. Project Structure

- main.sh – Main application and menu.
- lib/functions.sh – Functions used by the application.
- data/notices.txt – Stores notice records.
- data/archive.txt – Stores archived notices.
- backups/ – Stores backup files.
- logs/activity.log – Stores activity records.
- reports/ – Stores project reports and cron output.

## 5. Features

1. Post a new notice with the current date.
2. Display the latest five notices.
3. Search notices using keywords.
4. Display HIGH priority notices.
5. Archive notices older than 30 days.
6. View all notice data.
7. Create compressed backups using tar.
8. View activity logs.

## 6. Automation Using Cron

A cron job is configured to execute the archive function every Monday at 8:00 AM.

Cron expression:

0 8 * * 1

Command:

cd /home/ravi/linux_project/noticeboard && /home/ravi/linux_project/noticeboard/main.sh --cron

The cron service was checked and confirmed as active. The cron execution log was also verified.
